# Define goals

Create `{analysis_output_folder}/goals.md` from `assets/goals-template.md`. Derive a small set of project goals and instructional goals from the confirmed analysis findings. A goal is an intended broad outcome; do not turn it into a measurable learning objective yet. Tie each goal to the relevant gap and distinguish the instructional intervention from enabling non-training work.

Ask the user to correct material omissions or misprioritization. Then read fully and follow `[[bmad-snapshot:step-04-training-proposal.md]]`.

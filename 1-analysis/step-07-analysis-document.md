# Consolidate the design handoff

Create `{analysis_output_folder}/analysis-document.md` from `assets/analysis-document-template.md`. It is a traceable handoff, not a fresh analysis: reuse and cite the charter, learner/context/gap analyses, goals, approved proposal, and approved task analysis. Include an artifact index with paths and approval status, evidence and assumptions still open, the recommended intervention and non-training dependencies, and the task priorities that design must honor.

Ask the user for sign-off on the final analysis document. On sign-off, set its status to `approved` and report the package path, approved artifacts, open risks, and the explicit files `/addie-design` should receive. Stop if sign-off is withheld; do not represent the analysis as approved.

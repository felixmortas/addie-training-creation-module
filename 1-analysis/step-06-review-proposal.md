# Reconcile the proposal

Read the approved task analysis beside the approved proposal. Check whether its prioritized scope, prerequisites, dependencies, effort, schedule, cost, delivery assumptions, or expected benefits invalidate proposal claims. Update only the clearly identified sections, retain a dated change note, and ask the user to reapprove if any substantive commitment changed. Do not silently broaden scope.

When the proposal and task analysis agree, read fully and follow `[[bmad-snapshot:step-07-analysis-document.md]]`.

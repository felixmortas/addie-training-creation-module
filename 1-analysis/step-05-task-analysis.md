# Analyze required performance

Read the approved proposal and `goals.md`. Create `{analysis_output_folder}/task-analysis.md` from `assets/task-analysis-template.md`. For each instructional goal, identify the observable high-level tasks, rate importance, difficulty, teaching length, and development cost from 1–10, then decompose tasks hierarchically until prior knowledge takes over. Record dependencies, prerequisite knowledge, and explicit assumptions; do not invent subject-matter detail.

Present the prioritization and hierarchical task list. Halt for **Approve and continue**, **Approve and stop**, or **Revise task analysis**. Before recording approval, re-read the file from disk and preserve external edits. On approval, set status to `approved`; only then read `[[bmad-snapshot:step-06-review-proposal.md]]`.

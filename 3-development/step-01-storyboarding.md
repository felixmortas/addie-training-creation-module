# Storyboarding

> "A sample of what our product is going to look like."

Build a story board for the deliverable

## Storyboard fields

| Field | Purpose |
|---|---|
| Title / Name / # | Identifier |
| Files | Asset list (images, audio, video) |
| Mockup of screen | Visual layout |
| Notes for developer | Implementation hints |
| Text / Narration | Exact words on screen + voice-over |
| Navigation and Interactivity | What buttons do, where they go |

## Visual layout : Quick prototyping

For the visual, describe the layout of the screen using json.    

Here are the slides types possibilities:
title
section
message

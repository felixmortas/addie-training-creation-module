# Design aligned assessments

Read `assets/assessment-question-types.md` before selecting an assessment. For each objective, choose a post-assessment type from that catalogue and write a concise assessment prompt or performance brief that directly elicits the objective's behavior under equivalent conditions. A named hybrid may combine catalogue types, but must state its source types.

Check validity (it measures the stated objective) and reliability (another administration or rater would score it consistently). Write sound selected-response items: one unambiguously correct answer, correct grammar, plausible distractors, no answer-pattern cueing, no “all/none of the above,” and highlight **NOT** when it is necessary. Avoid absolute “always” and “never” unless they are factually required.

For a performance assessment, include an analytic rubric with observable, separately scored criteria and weights that reflect the objective. Do not use subjective labels, combined criteria, or equal weighting for unequal importance.

Do not create a pre-assessment; it repeats this post-assessment with different values. When every objective has a valid post-assessment, read fully and follow `[[bmad-snapshot:step-03-strategies.md]]`.
